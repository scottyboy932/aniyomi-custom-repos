**Anikoto Custom - Aniyomi Extension Repository (GitHub Hosted)**

Add this URL in Aniyomi:

https://raw.githubusercontent.com/scottyboy932/aniyomi-custom-repos/repo/index.min.json

## Source Code

Development happens in the fork:
https://github.com/scottyboy932/aniyomi-extensions

The custom extension source lives at:
`src/en/anikototv/AnikotoTV.kt`

## For Personal Use + Roku

1. Clone your fork.
2. Build the .apk (Android Studio recommended).
3. Copy the APK to the `apk/` folder on the `repo` branch.
4. Update `index.json` on the `main` branch of this repo.
5. Regenerate `index.min.json` and push to the `repo` branch.

Once the extension is installed on your phone, it works via screen mirroring to your Roku 4K Stick.

This setup keeps everything under your control on GitHub.
